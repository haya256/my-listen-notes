# 料金・プラン(フリーとプレミアムプラン)

## 要点

- LISTENには無料の「フリー」と、有料の「プレミアムプラン」(ブロンズ 500円・シルバー 1,000円・ゴールド 2,000円・プロ 5,000〜25,000円・ビジネス 要相談)がある。価格は税込の月額
- 公開のポッドキャストの数と、AI文字起こしは、フリーでも無制限。プランで大きく違うのは、**ビデオポッドキャストの配信時間**、**限定公開・非公開のポッドキャストの数**、**フォロワー限定・有料エピソードの時間**、サマリー・チャプターを作れる過去のエピソードの数など
- 申し込み・変更・解約は、ログインしてから画面右上のアイコン →「プラン」で行う。解約は「フリーへの変更」として行い、今の契約期間が終わるまでは有料プランのまま使える

## プランの比較

- コミュニティ機能と、エピソードの有料販売は、どのプランでも使える
- ビデオの時間は、どのプランも「直近30日間」で数える(下の「ビデオの利用時間の数え方」)

### プロ

ビデオの利用時間で月額が変わる。どの時間でも、使える機能は同じ。料金・プランのページには「お仕事でのご利用」と書かれている。

| ビデオの利用時間(直近30日間) | 月額(税込) |
|---|---|
| 20時間 | 5,000円 |
| 40時間 | 10,000円 |
| 60時間 | 15,000円 |
| 80時間 | 20,000円 |
| 100時間 | 25,000円 |

### ビジネス

料金は「カスタム」(要相談)。法人での利用、請求書の発行、個別のカスタマイズ、もっと大きなビデオの配信枠に対応する。申し込み・変更・解約は、メール(info@ond-inc.com)で問い合わせる。

## 手順

### 申し込む(フリー → 有料プラン)

1. LISTENにログインし、トップページ右上のアイコンを選ぶ
2. 「プラン」を選ぶ
3. 使いたいプランの「プランを選択」を選ぶ。プロの場合は、先にビデオの利用時間を選んで、表示された月額を確かめる
4. カード情報を入力して「申し込む」を選ぶ

- 申し込むとすぐに有料プランになり、料金がかかる
- OND inc. から領収書がメールで届く

### 有料プランを変える(上げる・下げる)

1. 画面右上のアイコン →「プラン」を開く
2. 変えたいプラン(プロの場合はビデオの利用時間)を選び、料金と内容を確かめて手続きする

- 変更はすぐに反映される。上げるだけでなく、下の有料プランにも変えられる
- 次の更新日は変わらない。差額は日割りで計算され、次の請求に反映される
- 下のプランに変えると、すぐに変更後のプランの機能と上限になる

### 解約する(有料プラン → フリー)

1. 画面右上のアイコン →「プラン」を開く
2. 変更先として「フリー」を選び、手続きする

- 今の契約期間が終わるまでは、有料プランの機能を使える。期間が終わると、自動でフリーになる
- 解約しても、アカウント・ポッドキャスト・エピソードは消えない

## ビデオの利用時間の数え方

- 毎月1日にリセットされるのではなく、**アップロードする時点から直近30日間の合計**で数える
- プランを変えても、使った時間はリセットされない
- 配信元のユーザーが同じ番組は、複数あっても**同じ利用時間を分け合う**
- 公開済みのエピソードのビデオだけでなく、エピソードにまだ紐づいていない「ビデオストック」(アップロード中・処理中・準備完了)も数に入る。そのため、公開済みのエピソードの合計時間と合わないことがある
- 残り時間は、ビデオのアップロード画面(「利用上限のうち残り何分」)や、「プラン」の画面のバーで確かめられる。反映には最大1時間かかることがある。番組ごとの内訳は表示されない

## メモ

- **自分の感想(公式の情報ではない)**:フリーから有料にする理由として特に大きいのは、「毎朝届くポッドキャストダイジェスト」と「イベントの作成・管理」だと感じた。ほかの違いの多くは「上限が増える」ものだが、この2つはフリーでは使えない機能で、一番安いブロンズ(500円)から使える
- **下のプランに変えるときの落とし穴**:使った時間が変更先の上限を超えていると、上限の内側に戻るまで新しいビデオをアップロードできない(例:直近30日間で2時間使った状態で、上限1時間のプランに変えると、使った時間が1時間以下になるまでアップロードできない)。限定公開・非公開ポッドキャストの数などの上限も下がるので、変える前に確かめる
- **日付を指定した変更の予約はできない**。変えたい日に自分で手続きする
- **変更が画面に出ないとき**:ページを再読み込みする →「プラン」の画面で今のプランを見る → ログアウトしてログインしなおす → OND inc. からのメールを確かめる。それでも直らなければ、[お問い合わせ](https://listen.style/document/contact_us) へ
- 「月間20分」(料金・プランのページ)と「直近30日間で20分」(プレミアムプランのドキュメント)のように、ページによって書き方が違うところがある。数え方はどちらも直近30日間と読める
- ライブ配信の「LISTENライブ」は、プランに関係なく全ユーザーが無料で使える(2026年2月のリリース時点)。[01-live-stream.md](01-live-stream.md) を参照
- 次のことは公式の案内に書かれておらず、未確認:年払いがあるか、カード以外の支払い方法(ビジネスの請求書払いを除く)、フリーで限定公開・非公開ポッドキャストを作れないことの明記
