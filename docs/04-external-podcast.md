# LISTEN以外で配信している番組をLISTENにつなぐ

> この記事では、ポッドキャストの配信サービスの Spotify for Creators と stand.fm での操作も扱います。Spotify for Creators と stand.fm は LISTENの公式機能ではありません。各サービスの画面や規約は、それぞれの公式の案内を確認してください。

## 要点

- 外部のサービスで配信している番組は、番組の **RSS URL** をLISTENの「ダッシュボード」→「ポッドキャストを追加」に入れると登録できる。配信元はLISTENに移らない(元のサービスで公開したエピソードが、RSS を通じてLISTENに取りこまれる)
- 登録しただけでは足りず、**オーナー認証**が要る。元のサービスで番組の説明欄にLISTENの認証用リンクを貼り、LISTENで「ポッドキャストを認証する」を押す
- オーナー認証すると、番組の設定・分析、AI文字起こし、LISTENだけのエピソードの追加、動画の追加などが使えるようになる

## 用意するもの

- LISTENのアカウント
- 外部のサービスで配信している番組の RSS URL
- 外部のサービスで、番組の説明を編集できる権限

## 手順

### 1. 外部のサービスで RSS URL を調べる

RSS URL の場所はサービスによって違う。番組の設定や配信の設定で「RSSフィード」「RSS URL」を探す。公式ドキュメントでは、次の2つの例が紹介されている。

**Spotify for Creators**

- Web版:ログイン →「設定」→「配信可否」→「RSS配信」までスクロールし、RSS フィードをコピーする。RSS フィードが有効になっていなければ、同じ画面で有効にする
- スマートフォンのアプリ:ポッドキャストを開く → 番組タイトルの下の「詳細を編集」→ 下にスクロールし、「RSSフィード」の右下の「コピー」
- 最初のエピソードを公開するまで、RSS フィードが表示されないことがある。また、RSS フィードを有効にすると、RSS に登録しているメールアドレスが公開される

**stand.fm**

- アプリで「マイページ」→ 下にスクロールして「設定」→「ポッドキャスト設定」→ チャンネル画像の下の「RSS URLをコピー」

### 2. LISTENに登録する

1. LISTENにログインし、画面右上のアイコンから「ダッシュボード」を開く
2. 「ポッドキャストを追加」を選び、「ポッドキャストのフィードURL」に、手順1でコピーした RSS URL を入れる
3. 「送信」を押す

番組の情報とエピソードの取りこみが始まる。エピソードが多いと時間がかかる。

### 3. オーナー認証をする

1. ダッシュボードで登録した番組を開き、表示される「LISTENの認証用リンク」をコピーする
2. 元のサービスで、番組の説明欄に認証用リンクを貼って保存する
   - Spotify for Creators(Web版):画面左の「設定」→「ポッドキャスト」→「ポッドキャストの説明」に貼って「保存」。スマートフォンのアプリでは、「ポッドキャスト」→「詳細を編集」→「説明」に貼って「保存」
   - stand.fm:「マイページ」→ 一番上のアイコン部分 →「プロフィール編集」→「チャンネル説明」に貼って「完了」
   - 公式のおすすめ:「ポッドキャストの書き起こしサービス「LISTEN」はこちら」のような一言を添えると、何のリンクかわかりやすい
3. 説明欄の変更が RSS に反映されたら、LISTENのダッシュボードに戻って「ポッドキャストを認証する」を押す

**認証エラーが出たとき**:反映まで数分かかることがある。ダッシュボードの「RSSの内容を確認する」を開き、番組の説明に認証用リンクが入っているか見る。入っていなければ、少し待ってからもう一度押す。

説明欄にリンクを貼るのは、番組を実際に管理している本人が登録していることを確かめるため。

## 登録したあとにできること

### LISTEN限定エピソードを足す

自分の番組ページの「新しいエピソードを作成する」から、LISTENだけで公開するエピソードを作れる。元のサービスには反映されない。

- 入れるもの:音声ファイル、タイトル、概要(画像と公開日時は入れなくてもよい)
- 公開のしかた:「下書き保存する」「公開予約」「公開する」の3つ

### LISTEN上の RSS を使い分ける

番組ページの RSS のメニューから、目的に合わせてコピーできる。

| メニュー | 中身 |
|---|---|
| LISTENのRSS URLをコピー | 外部から取りこんだエピソードと、LISTENで足したエピソードの両方 |
| オリジナルRSSのURLをコピー | 元のサービスが配信している RSS |
| LISTENでホストされたエピソードのみのRSS URLをコピー | LISTENで足したエピソードだけ(LISTEN限定エピソードがあるときだけ出る) |

### 動画を足す

外部の番組のエピソードにも、LISTEN上で動画を足せる(元の音声の配信は変えなくてよい)。エピソードの詳細ページの「編集」→「ビデオをアップロード」。公開前に動画を用意しておく「ビデオストック」もある。動画の時間はプランの上限に数えられる([02-plans.md](02-plans.md) を参照)。

### 取得元の RSS を変える(配信サービスを引っ越したとき)

1. ダッシュボードで番組の「設定」を開く
2. 「ポッドキャスト情報を編集」の「外部RSS URL」に、新しい RSS URL を入れる
3. 「RSS URLを変更」を押す

- これまでのエピソードページ、文字起こし、コメントは引きつがれる。番組の公開範囲と文字起こしの設定も変わらない
- エピソードを見分ける情報が変わった、昔のエピソードが新しい RSS に入っていない、新しい RSS がすでにLISTENに登録されている、といった場合は、画面から変えられないことがある。そのときは運営(info@ond-inc.com)に相談する

### 新しいエピソードをすぐ取りこませる(RSS再取得API)

ふだんはLISTENが定期的に RSS を取りに行く。元のサービスで公開した直後にすぐ取りこませたいときは、「RSS再取得API」で頼める(オーナー認証した番組だけ。同じ番組は5分に1回まで)。プログラムから使うもので、使い方は [APIドキュメント](https://listen.style/api-docs/rss-refresh) にある。

## メモ

- **実機で確かめたこと(2026-11-15、stand.fm から登録した番組の画面)**:ダッシュボードで番組を選ぶと「分析」「エピソード」「推薦」「感想」「コメント」「視聴者」「売上」「設定」「他サービス連携」のタブが並ぶ。「設定」タブに「ポッドキャスト情報を編集」(「外部RSS URL」「ポッドキャストのフィードURL」「RSS URLを変更」)と「ポッドキャストの設定」(「ポッドキャストの公開範囲」「文字起こしの公開範囲」など)の欄がある。登録・オーナー認証の手順そのものは実機で試していない
- **自分が登録しなくても、番組ページができていることがある**:LISTENでは、リスナーが公開の RSS を登録すると、その番組のページができる。オーナー認証していない番組は、LISTENのAI文字起こしの対象にならない。未認証の番組ページに出る説明文は、RSS に書かれているもの
- **文字起こしをしたくないとき**:オーナー認証すると、設定によっては文字起こしの対象になる。したくなければ、ダッシュボードで番組の「設定」→「ポッドキャストの設定」の「自動で文字起こしを行う」をオフにして、欄の一番下の「送信」を押す(自動の文字起こし・要約・話者分離が止まる。作成済みの文字起こしは消えない)。公式の方針のページには「文字起こしの公開範囲」で「文字起こししない」を選ぶと書かれているが、2026-11-15 に実機で見たときは、その選び方はなかった。すでにある文字起こしを人に見せたくないときは、「文字起こしの公開範囲」を「管理者のみに公開」にする
- **LISTENに載せたくないとき**:オーナー認証してから、番組の「設定」→「ポッドキャストの公開範囲」で「LISTENへの掲載停止(非公開)」を選び、欄の一番下の「送信」を押す(公式の方針のページには「その場で保存される」とあるが、実機では公開範囲の変更は「送信」を押さないと反映されなかった)。実機の画面では、この欄の選び方は「公開」「フォロワー限定」「限定公開」「LISTENへの掲載停止(非公開)」の4つで、欄の下に掲載停止の説明文も出ている。「フォロワー限定」と「限定公開」は薄い色で表示されていて、選べない状態に見えた(理由は未確認)。無料で、有料プランの「非公開の番組」の数にも入らない。LISTEN上ではオーナーだけが見られるようになり、RSS の取得も止まる。元のサービスの番組や RSS は非公開にならない。同じ RSS を他の人が登録しなおしても、掲載は再開されない。戻すときは「公開」を選ぶ。[03-private-podcast.md](03-private-podcast.md) も参照
- **元のサービスで番組を消してしまったとき**:説明欄に認証用リンクを貼れないので、自分ではオーナー認証できない。LISTENの番組ページの URL、番組名、元のサービス名、削除済みであること、本人だとわかる情報をそえて、運営(info@ond-inc.com)に問い合わせる
- **再生数の数え方**:元のサービスが配信する音声ファイルの再生は、LISTENの「メディア再生数」には入らない。LISTENのブラウザ版やアプリでの再生は「LISTEN再生数」に入る
- 次のことは公式の案内に書かれておらず、未確認:オーナー認証が終わったあと、説明欄の認証用リンクを消してもよいか
