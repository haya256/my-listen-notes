# ライブ配信のやり方(LISTENライブ)

> この記事では、配信ソフトの OBS と、同時配信先の YouTube(YouTubeライブ)も扱います。OBS と YouTube は LISTENの公式機能ではありません。各サービスの使い方や規約は、それぞれの公式の案内を確認してください。

## 要点

- LISTENのライブ配信機能は「LISTENライブ」。番組ページの「編集」→「ライブ配信を管理」→「ライブ配信を作成」で作り、表示される SRT サーバーの URL を OBS などの配信ソフトに設定して配信する
- YouTubeのストリームキーをLISTENに設定しておくと、LISTENが映像と音声を YouTubeライブにも転送する(同時配信)
- 配信した音声は自動でアーカイブされ、そのままポッドキャストのエピソードとして公開できる(AI文字起こしもつく)。アーカイブされるのは1回のライブにつき最初の12時間まで
- LISTENライブは全ユーザーが無料で使える。YouTubeライブへの同時配信も追加料金なし(2026年2月のリリース時点)

## できること

| 機能 | 内容 |
|---|---|
| 音声・動画のライブ配信 | LISTEN上で配信する。視聴する人は画面右上の「Video / Audio Only」で、映像ありと音声のみを切り替えられる |
| YouTubeライブへの同時配信 | OBS から送った映像と音声を、LISTENが YouTube にも転送する |
| 自動アーカイブ | 配信が終わると音声が保存され、編集なしでエピソードとして公開できる。AI文字起こしもされる |
| 音声だけ区切る | YouTube側の映像は流し続けたまま、LISTEN側の音声ライブだけを「開始」「終了」できる。長い公開収録を、テーマごとのエピソードに分けられる |
| チャットオーバーレイ | 配信画面にLISTENのコメントを重ねて表示できる |

## 手順

### 1. LISTENでライブ配信を作る

1. 自分の番組ページの右上の「編集」から「ライブ配信を管理」を選ぶ
2. 画面右上の「ライブ配信を作成」を選ぶ
3. 配信ページに表示される「🔴SRTサーバー」の URL を控える

### 2. OBS から配信する

1. OBS の配信の設定に、手順1で控えた SRT サーバーの URL を貼り付ける
2. OBS で配信を開始する

OBS のどの画面のどの欄に貼るか(「サービス」を「カスタム」にする、など)は、公式ドキュメントには詳しく書かれていない(未確認)。

送り方(プロトコル)は SRT がおすすめで、従来の RTMP にも対応している(LISTENのブログ・プレスリリースより)。RTMP で送るときの URL をどこで取得するかは、書かれていない(未確認)。

### 3. YouTubeライブにも同時配信する(使うときだけ)

1. 先に YouTube で YouTubeライブを作り、次の2つを取得する
   - **ストリームキー**(配信のデータを送るためのもの)
   - **視聴ページの URL**(視聴する人が開くページ。YouTube Studio の「共有」または「YouTubeで表示」から取得できる)
2. LISTENの「ライブ配信を管理」の画面で、ストリームキーを「YouTubeストリームキー」に、視聴ページの URL を「YouTubeライブURL」に入力する
3. ストリームキーを設定・変更したら、**OBS の配信をいったん止めて、もう一度開始する**

### 4. コメントを配信画面に出す(使うときだけ)

1. 「ライブ配信を管理」の画面で「チャットオーバーレイURL」を取得する
2. OBS の「ブラウザ」ソースにその URL を入れる

### 5. 配信が終わったら

- 音声は自動でアーカイブされる。そのままポッドキャストのエピソードとして公開できる
- 配信後のライブ配信ページでは、チャットのログやリスナーの反応を見られる(公式の例:https://listen.style/live/4b211c67-fe08-45c6-8a3a-f95f63af3618 )

## OBSの設定例

LISTENの公式ドキュメント・ブログ・プレスリリースには、OBS の画質・音質の推奨値は書かれていない(2026-11-15 時点)。以下は、自分の OBS の設定(「設定」→「出力」、出力モード「基本」)と、それについて一般論から考えたこと。**この設定で実際に配信して確かめたわけではない(未確認)。**

| 項目 | 設定例 | コメント(マニュアル外の一般論) |
|---|---|---|
| 映像ビットレート | 6000 Kbps | 1080p・30fps でも 720p でも、YouTubeライブとして無理のない値。解像度とフレームレートは「映像」タブで決まる |
| 音声ビットレート | 160 | 配信の音声はそのままエピソードになるので、映像より音声の質が大事。192〜256 に上げてもいい(映像の 6000 に比べれば、上げても負担はほとんど増えない) |
| 映像エンコーダ | ハードウェア (NVENC, H.264) | GPU で処理するので PC の負担が軽い。YouTube に送るなら H.264 が無難 |
| エンコーダプリセット | P5: Slow (高品質) | 配信の定番 |
| 音声エンコーダ | AAC (既定値) | そのままでよい |
| 録画品質 | 配信と同じ | 手元にも録画を残しておく。ネットが切れたときや、12時間を超えてアーカイブに残らなかったときの保険になる |
| 録画フォーマット | Hybrid MP4 (.mp4) | OBS が途中で落ちても、ファイルが壊れにくい |

ほかに気をつけること(マニュアル外の一般論):

- **キーフレーム間隔**:YouTubeライブでは「2秒」が推奨。出力モードが「基本」だとこの欄が表示されない。確実に決めたいなら、出力モードを「詳細」にして「キーフレーム間隔」を 2 s にする
- **「音声」タブのサンプルレート**:48 kHz が無難
- **回線**:6000 + 160 Kbps を安定して送るには、上りの速さに余裕(目安は 1.5倍程度、10 Mbps 以上)が要る。SRT は UDP という通信の方式を使うので、会社などのネットワークでは通らないことがある
- **本番の前に**:短いテスト配信をして、LISTENのアーカイブの音質と、YouTube の画質を確かめる。LISTEN側で音声や映像を作り直しているかは、わかっていない

## メモ

- **アーカイブは最初の12時間まで**。12時間を超えた部分は、アーカイブにも文字起こしにも入らない。ただし配信そのものは12時間で止まらない。全部残したいときは、音声ライブを12時間以内に区切る
- **YouTube Studio に「データなし」と出るとき**:ストリームキーを設定する前から OBS がつながっていると、YouTube にデータが送られないことがある。OBS の配信をいったん止めて、開始しなおす
- **「YouTubeライブURL」にストリーム URL を入れない**:`https://a.rtmp.youtube.com/live2` のような URL はデータを送るためのもので、YouTube のチャットの取得には使えない。視聴ページの URL を入れる
- **「イベント用ライブ配信ツール」は別の機能**:LISTENのイベント機能で作ったイベントのバナーやスロット(枠)の情報を、OBS の配信画面に重ねて出すための機能。イベントの管理・運営ページの「ライブ配信ツール」から、「コントローラーページ」(OBS のカスタムブラウザドックに入れて操作する)と「オーバーレイページ」(OBS のブラウザソースに入れる)の URL を取得する。これらの URL は SNS や公開ページに載せず、配信の担当者だけで共有する
- **配信時間の制限**:2026年2月のリリース時点では、配信時間の制限は設けていないとのこと(アーカイブの12時間の上限とは別の話)
- 次のことは公式の案内に書かれておらず、未確認:スマートフォンのアプリから配信できるか、OBS 以外の配信ソフトで使えるか
