# 限定公開・非公開ポッドキャスト(番組の公開範囲)

## 要点

- 番組(ポッドキャスト)の公開範囲は「公開」「フォロワー限定」「限定公開」「非公開」の4つ。「限定公開」はアクセスコードを知っている人だけ、「非公開」は番組の管理権限を持つアカウントだけが見られる
- 設定は「ダッシュボード」→ 番組を選ぶ →「設定」タブ →「ポッドキャストの設定」の「ポッドキャストの公開範囲」
- 限定公開・非公開の番組を作れる数はプランで決まる(ブロンズ 1個・シルバー 2個・ゴールド 5個・プロ 10個)。フリーの一覧には載っていない。フォロワー限定の番組はこの数に入らないらしいが、上限に達するとフォロワー限定も選べなくなる(メモを参照)。[02-plans.md](02-plans.md) を参照

## 番組の4つの公開範囲

| 公開範囲 | 見られる・聴ける人 | 番組ページ | 外部サービスへの配信(RSS) |
|---|---|---|---|
| 公開 | 誰でも | 誰でも見られる | できる |
| フォロワー限定 | LISTENで番組をフォローしている人 | フォローしていない人にも見える(フォロワー限定であることと、フォローボタンが出る) | できない(RSS が配信されない) |
| 限定公開 | アクセスコードを知っている人 | アクセスコードが必要 | 公式に記載なし(未確認) |
| 非公開 | 番組の管理権限を持つアカウントだけ | 管理者だけ | 公式に記載なし(未確認) |

- **フォロワー限定**:外部のサイトに埋め込んだプレイヤーでも、フォローしていない人は再生できない
- **限定公開**:番組を共有するときは、番組ページの URL とアクセスコードを相手に伝える
- **非公開**:公式の使い道の例は、個人的な音声日記、社内用の記録、公開前の音声の確認

## 手順

### 番組の公開範囲を変える

1. LISTENにログインし、画面右上のアイコンから「ダッシュボード」を開く
2. 公開範囲を変えたい番組を選ぶ
3. 「設定」タブを開き、下のほうの「ポッドキャストの設定」の欄まで進む
4. 「ポッドキャストの公開範囲」で、公開範囲を選ぶ。**選んだ瞬間に保存される**(「送信」を押さなくても反映される)
5. 「限定公開」を選んだときは、アクセスコードの入力欄が出るので入力する(3〜32文字。使える文字は半角英数字、ハイフン `-`、アンダースコア `_`)。アクセスコードがどうやって保存されるかは未確認

> **要注意**:「ポッドキャストの公開範囲」は、ドロップダウンで選んだ瞬間に変更が反映される。同じ欄の一番下に「送信」ボタンがあるが、公開範囲には関係ない。中身を見るつもりで選んだだけでも公開範囲が変わってしまう。下の「注意:『ポッドキャストの設定』の欄の保存のしかた」を参照。

公式の「オーナー未認証ポッドキャストについてのLISTENの方針」のページの「公開範囲の変更はその場で保存されます」が、今の画面と合っている。「公開範囲を設定する」のページは「送信」を押すと書いているが、今の画面とは違う。

## 注意:「ポッドキャストの設定」の欄の保存のしかた

「設定」タブの「ポッドキャストの設定」の欄には、**選んだ瞬間に保存される項目**と、**欄の一番下の「送信」を押すまで保存されない項目**が、ひとつのまとまりの中に混ざっている。どの項目がどちらなのかは、画面にも公式ドキュメントにもはっきり書かれていない。

| 項目(画面の上から順) | 保存のしかた |
|---|---|
| ポッドキャストの公開範囲 | **選んだ瞬間に保存される**(実機で確認) |
| 感想の公開設定 | 未確認(「送信」で保存されると思われる) |
| 推薦の公開設定 | 未確認(同上) |
| コメントの公開設定 | 未確認(同上) |
| 番組の言語 | 未確認(同上) |
| 自動で文字起こしを行う | 未確認(同上) |
| 文字起こしの公開範囲 | 「送信」を押すまで保存されない(実機で確認。画面にも「『送信』で変更を保存してください」と出る) |
| 文字起こしの言語 | 未確認(「送信」で保存されると思われる) |
| サマリーを生成する | 未確認(同上) |
| 話者分離を行う | 未確認(同上) |
| 支払い先ユーザーを選択してください | 未確認(同上) |

気をつけること:

- 「ポッドキャストの公開範囲」は、試しに選んだだけで番組の公開範囲が変わる。見るだけのつもりなら、ドロップダウンを開いても選ばずに閉じる
- ほかの項目は、変えたら「送信」を押さないと保存されない(と思われる)。押し忘れると、変えたつもりで変わっていない
- 「設定」タブのほかの欄(「コミュニティ情報」「おたよりフォーム」「エピソード編集の合言葉」など)には、欄ごとに「保存」ボタンがある。「ポッドキャスト情報を編集」は、LISTENで配信している番組では「送信」、外部の RSS の番組では「RSS URLを変更」のボタンで保存する
- 変えたあとは、ページを読みこみなおして、本当に変わったか(変わっていないか)を確かめると安心

**自分の感想(公式の情報ではない)**:メニューを後から付け足していくうちに、こういうわかりにくい作りになったのではないかと思う。

## エピソードと文字起こしの公開範囲

番組の公開範囲とは別に、エピソードごと・文字起こしごとにも公開範囲を決められる。

### エピソードの公開範囲

公開中の番組で、エピソードの作成・編集画面の「エピソードの公開範囲・有料設定」から選ぶ。

| 公開範囲 | 内容 |
|---|---|
| 公開(ポッドキャストの設定に準ずる) | 誰でも聴ける。番組がフォロワー限定・限定公開・非公開なら、番組の公開範囲が優先される |
| フォロワー限定 | 番組をフォローしている人だけが聴ける。フォローしていない人にも、エピソードがあることは見える。「フォロワー限定」マークが付く |
| 有料 | 購入した人だけが聴ける |

フォロワー限定・有料エピソードに使える時間は、プランで決まる(フリーは月1時間まで)。

### 文字起こしの公開範囲

番組の「設定」タブ →「ポッドキャストの設定」の「文字起こしの公開範囲」で選び、欄の一番下の「送信」を押す。エピソードの公開範囲とは別の設定で、文字起こしの公開範囲を変えても、音声や動画の公開範囲は変わらない。

| 公開範囲 | 読める人 |
|---|---|
| 公開 | エピソードを見られる・聴ける人全員 |
| 公開(検索エンジンに載せない) | LISTENにログインしている人。Google などの検索エンジンには載らない |
| フォロワー限定 | 番組をフォローしている人と、管理・編集権限を持つアカウント |
| 管理者のみに公開 | 管理・編集権限を持つアカウントだけ |

画面に並ぶ選び方は、上の4つだけ(実機で確認)。公式の「公開範囲を設定する」のページでは4つ目を「管理者限定」と書いているが、画面の表示は「管理者のみに公開」。また、公式の「オーナー未認証ポッドキャストについてのLISTENの方針」のページには、この欄で「文字起こししない」を選べると書かれているが、画面にはなかった。

同じ欄の「自動で文字起こしを行う」をオフにすると、自動の文字起こし・要約・話者分離が止まる(作成済みの文字起こしは消えない)。同じ欄には「文字起こしの言語」「サマリーを生成する」「話者分離を行う」もある。

## メモ

- **実機で確かめたこと(2026-11-15、外部の RSS から登録した番組の画面)**:ダッシュボードで番組を選ぶと「分析」「エピソード」「推薦」「感想」「コメント」「視聴者」「売上」「設定」「他サービス連携」のタブが並ぶ。公式の「公開範囲を設定する」のページにある「公開範囲・文字起こしの設定」という名前のタブはなく、「設定」タブの「ポッドキャストの設定」の欄に、「ポッドキャストの公開範囲」と「文字起こしの公開範囲」がある。「ポッドキャストの公開範囲」は選んだ瞬間に保存される。「文字起こしの公開範囲」は、欄の一番下の「送信」を押さないと反映されない(画面にも「「送信」で変更を保存してください」と出る)。「文字起こしの公開範囲」の選び方は「公開」「公開(検索エンジンに載せない)」「フォロワー限定」「管理者のみに公開」の4つ。外部の RSS から登録したこの番組では、「ポッドキャストの公開範囲」の選び方は「公開」「フォロワー限定」「限定公開」「LISTENへの掲載停止(非公開)」の4つで、「非公開」はなく、かわりに「LISTENへの掲載停止(非公開)」がある。「フォロワー限定」と「限定公開」は薄い色で表示されていて、選べない状態に見えた。理由は、そのとき別の番組で非公開の番組が1つあり、ブロンズの上限(1個)に達していたからだと考えられる(下の項目を参照)
- **実機で確かめたこと(2026-11-15、LISTENで配信している番組の画面)**:タブの並びと、「設定」タブの「ポッドキャストの設定」の欄の作りは、外部の RSS の番組と同じ(文字起こしの設定も同じ)。「ポッドキャストの公開範囲」の欄の下には「LISTEN配信の番組を非公開にするには、非公開番組の利用枠がある有料プランへの加入が必要です。」と表示される。「ポッドキャストの公開範囲」の選び方は「公開」「フォロワー限定」「限定公開」「非公開」の4つ。ブロンズ(1個まで)で、非公開の番組1つとフォロワー限定の番組1つがある状態では、「公開」以外の3つが薄い色で、選べなかった。非公開の番組を削除すると、フォロワー限定の番組が1つ残っていても、3つとも選べるようになった
- **秘密の内容は番組ごと絞る**:文字起こしの公開範囲を絞っても、文字起こしの中身がLISTEN内の全文検索に使われることがある、と公式に書かれている。機密性の高い内容は、番組やエピソードの公開範囲も絞る
- **外部の RSS から取りこんだ番組**:「LISTENへの掲載停止(非公開)」を選べる(オーナー認証が済んだ番組だけ)。LISTEN上ではオーナーだけが見られる状態になり、LISTENが RSS を取りに行くのも止まる。元の配信サービスの番組や RSS が非公開になるわけではない。戻すときは「公開」にする
- **フォロワー限定の番組は、プランの数に入らないらしい**:料金・プランのページでは「限定公開・非公開ポッドキャスト」の数とされているが、公開範囲のドキュメントには「フォロワー限定、限定公開、非公開に設定できる番組数は、プランによって異なる」とある。実機では、非公開の番組を削除すると、フォロワー限定の番組が1つ残っていても、ブロンズ(1個まで)で3つとも選べるようになった。数に入るのは料金・プランのページのとおり限定公開と非公開だけで、その数が上限に達すると、画面は「フォロワー限定」もまとめて選べなくする、と考えられる。つまり上限に達していると、フォロワー限定の番組も新しく作れない(実機の様子からの推測で、公式に明記はない)
- **プランを下げたとき**:シルバーからブロンズに下げたあとも、シルバーのときに作った非公開の番組とフォロワー限定の番組は、どちらもそのまま残っていた(2026-11-15 に実機で確認)。ただ、数に入るのが非公開の1つだけなら、ブロンズの上限(1個)は超えていない。上限を超えたときに番組がどうなるかは未確認。公式には、下のプランに変えると「変更後のプランの機能と利用上限が適用されます」としか書かれていない
- 次のことは公式の案内に書かれておらず、未確認:フリーで限定公開の番組を作れるか(料金・プランのページの一覧に載っていない。非公開は、上の画面の表示から有料プランが必要とわかる)、限定公開・非公開の番組で RSS が配信されるか、プランを下げて上限を超えたときに、すでにある番組がどうなるか
