# 公開しない・一部だけに見せる音声のパターン

## 要点

- 「LISTENに音声はあるが、広く公開していない」状態は、大きく **エピソード単位**(下書き・公開予約・フォロワー限定・有料)と **番組単位**(フォロワー限定・限定公開・非公開・掲載停止)に分かれる。番組の公開範囲のほうが優先される
- 選ぶときの軸は「**誰に聴かせたいか**」(自分とメンバーだけ/コードを知っている人/フォロワー/お金を払った人)と「**外部のアプリ(RSS)に流すか**」
- 下書きは、エピソードページの「編集」メニューの「**プレビューリンクをコピー**」で、メンバーでない人にも見せられる(と思われる)。この機能は公式ドキュメントに記載がない

## 全体の比較

| パターン | 単位 | 聴ける人 | 外部アプリ(RSS) | プランの制限 | くわしく |
|---|---|---|---|---|---|
| 下書き | エピソード | 番組の管理者・共同管理者・編集者・その回の出演者 | 出ない(と思われる) | なし(公式に記載なし) | 下の「下書き・公開予約」 |
| 公開予約(公開日時の前) | エピソード | 公開日時までは下書きと同じ(と思われる)。日時になると自動で公開 | 公開日時から(と思われる) | なし(公式に記載なし) | 下の「下書き・公開予約」 |
| 下書きのプレビューリンク | エピソード | リンクを知っている人(と思われる。ログインが要るかは未確認) | — | なし(と思われる) | 下の「下書きのプレビューリンク」 |
| フォロワー限定エピソード | エピソード | 番組をフォローしている人。フォローしていない人にも、エピソードがあることは見える | 公式に記載なし(未確認) | フォロワー限定・有料エピソードの時間(フリーは月1時間) | [03-private-podcast.md](03-private-podcast.md) |
| 有料エピソード | エピソード | 購入した人。無料プレビュー(試聴)を付けられる | 公式に記載なし(未確認) | 同上の時間。作れる数にも制限あり(下のメモ) | 下の「有料エピソード」 |
| フォロワー限定の番組 | 番組 | 番組をフォローしている人 | 出ない(RSS が配信されない) | 数には入らないらしい(推測) | [03-private-podcast.md](03-private-podcast.md) |
| 限定公開の番組 | 番組 | アクセスコードを知っている人 | 公式に記載なし(未確認) | 限定公開・非公開の番組の数(ブロンズ1個〜) | [03-private-podcast.md](03-private-podcast.md) |
| 非公開の番組 | 番組 | 番組の管理権限を持つアカウントだけ | 公式に記載なし(未確認) | 同上 | [03-private-podcast.md](03-private-podcast.md) |
| LISTENへの掲載停止 | 番組(外部の RSS の番組だけ) | LISTEN上ではオーナーだけ | 元の配信サービスの RSS はそのまま | なし(数に入らない) | [04-external-podcast.md](04-external-podcast.md) |
| rooom のメンバー限定 | rooom(LISTENとは別のサービス) | rooom の有料メンバー | 公式に記載なし(未確認) | rooom の手数料 | 下の「rooom」 |

関係が近いが、「音声を隠す」ものではないもの:

| もの | 内容 |
|---|---|
| 文字起こしの公開範囲 | 音声の公開範囲とは別に、文字起こしだけを「管理者のみに公開」などにできる。音声は公開のまま。[03-private-podcast.md](03-private-podcast.md) |
| LISTEN限定エピソード | 外部の RSS の番組に、LISTENだけで聴けるエピソードを足すもの。元の配信サービスには出ないが、LISTEN上では公開。[04-external-podcast.md](04-external-podcast.md) |

## 使い分け(ユースケース)

| やりたいこと | 向いているもの |
|---|---|
| 公開前に自分で聴きなおす・文字起こしを直す | 下書き |
| 共同で作っている人・出演者に、公開前に確認してもらう | 下書き(相手を番組の編集者にするか、その回の出演者として登録する) |
| メンバーでない人(ゲスト・スポンサーなど)に、公開前に一度だけ聴いてもらう | 下書きのプレビューリンク |
| 決まった日時に出したい | 公開予約 |
| 番組をフォローしてくれた人へのおまけ・フォローのきっかけ作り | フォロワー限定エピソード |
| 1本ごとに売りたい(講座・特別回など) | 有料エピソード(無料プレビューで冒頭を聴かせる) |
| 毎月の会費で、限定の音声・記事を届けたい | rooom |
| フォロワーにだけ届ける番組を、まるごと作りたい | フォロワー限定の番組 |
| 社内・家族・サークルなど、決まった人たちだけで聴く番組 | 限定公開の番組(アクセスコードを共有) |
| 自分だけの音声日記・社内の記録・公開前の音声置き場 | 非公開の番組 |
| 外部で配信している番組を、LISTENには載せたくない | LISTENへの掲載停止 |

選ぶときの考え方:

- **アカウントを持っていない人にも聴かせたいか**:限定公開(アクセスコード)以外は、LISTENのログインが前提になる(フォロー・購入・メンバー登録が要る)。限定公開で相手にログインが要るかは未確認
- **1本だけか、番組まるごとか**:1本だけならエピソード単位、まとめてなら番組単位。番組単位の限定公開・非公開は、プランで作れる数が決まる
- **公開前の確認だけなら下書きで足りる**:確認してもらう人を番組のメンバー(編集者)にするか、プレビューリンクを送れば、下書きを見せられる。わざわざ限定公開の番組を作らなくてよい

## 下書き・公開予約

エピソードを作るとき、公開のしかたを次の3つから選ぶ。

1. **下書き保存**:公開せずに保存する。あとで、トップページのアイコン → チャンネルページから編集・公開できる
2. **公開予約**:「詳細設定」で未来の公開日時を指定して「公開予約」を押す。その日時に自動で公開される
3. **すぐに公開**

下書きを見られる人(公式の「共同管理者・編集者を追加する」のページから):

| 人 | 下書き |
|---|---|
| オーナー・共同管理者 | 見られる・公開できる |
| 編集者 | 担当番組の全エピソード(非公開・下書きを含む)を見て、文字起こし・話者名・チャプターを編集できる。公開・削除・音声の差し替えはできない |
| その回の出演者(アカウントを紐づけた人) | 自分が出ている回は、下書きも編集できる |
| 「エピソード編集の合言葉」を知っているリスナー | 見られない(公開日時を過ぎた、全体公開のエピソードだけを編集できる) |

### 下書きのプレビューリンク

1. 下書きのエピソードのページを開く(タイトルの横に「下書き」と出る)
2. 右上の「編集」を開く
3. メニューの下のほうの「公開」の区切りにある「**プレビューリンクをコピー**」を選ぶ
4. コピーされたリンクを、聴いてほしい人に送る

- 2026-11-19 に、メニューにこの項目があることを実機で確認した。公式ドキュメントには記載がない
- 次のことは未確認:リンクを開くのにLISTENのログインが要るか、リンクに有効期限があるか、取り消せるか、公開後や公開予約のエピソードでも出るか、プレビューで文字起こしも見られるか

## 有料エピソード

- エピソードの作成・編集画面の「エピソードの公開範囲・有料設定」で「有料」を選び、価格を決める(50〜999,999円)
- 聴こうとすると購入画面が出て、買った人だけが聴ける
- **無料プレビュー**:秒数を決めると、その長さの試聴用の音声が作られる(作られるまで時間がかかることがある)
- 売上から手数料 20% を引いた額が収益になる

## rooom

- LISTENの運営元(株式会社OND)と株式会社雑談のメンバーシップサービス(rooom.listen.style)
- 月額 500円〜3万円で自由に決められ、年額の割引も付けられる。メンバー限定の記事・音声・動画や特典を届け、コメントやチャットで交流できる
- LISTENのエピソードや番組の公開範囲とどうつながるか(LISTENの番組のエピソードを rooom の限定にできるか、など)は、公式ページに記載がなく未確認

## メモ

- **実機で確かめたこと(2026-11-19)**:下書きのエピソードのページの「編集」メニューには、文字起こしの項目(「文字起こしエディタを開く」など)が並び、その下の「公開」の区切りに「プレビューリンクをコピー」「はてなブログに投稿」、一番下に「エピソードを削除する」がある。プレビューリンクを実際に開いて、どう見えるかは試していない
- **有料エピソードを作れる数**:公式の収益化のページには「プレミアムプランの限定公開エピソード作成可能数に準じます」とある。料金・プランのページの「フォロワー限定・有料エピソード」の時間(フリーは月1時間)のことと思われるが、「限定公開エピソード」という言い方はほかのページにない。エピソードの公開範囲の選び方にも「限定公開」はない(番組だけ)
- **rooom の手数料**:収益化のページでは「販売手数料は20%」、rooom のページでは「利益が出たときの8%(+決済手数料)」と書かれていて、合わない
- **番組の公開範囲が優先**:エピソードを「公開」にしても、番組がフォロワー限定・限定公開・非公開なら、番組の公開範囲になる
- 次のことは公式の案内に書かれておらず、未確認:下書き・公開予約のエピソードが RSS に出ないか、フォロワー限定・有料エピソードが RSS でどう扱われるか、限定公開の番組を聴くのにログインが要るか、ビデオストック(エピソードに紐づいていないビデオ)を誰が見られるか
